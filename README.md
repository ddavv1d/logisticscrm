# LogisticsCRM

CRM для контейнерной логистики по **Среднему коридору** (Грузия → Азербайджан → паром Каспий → Туркменистан → Узбекистан). Замена Excel: ручная смена стадий контейнеров, учёт денег по плечам, наглядный дашборд для владельца.

> **Статус:** предпроектная подготовка завершена, кода приложения ещё нет. Начинаем со среза 0.

## Роли
- **manager** — вводит данные, двигает стадии.
- **owner** — дашборд, выгрузки, сверка.
- **accountant** — деньги по плечам, «кто должен», маржа.

## Стек
React + Vite + Tailwind · FastAPI + PostgreSQL (async) · Argon2id + cookie-сессия · openpyxl (экспорт).

## С чего начать (для разработчика / новой сессии)
1. Прочитать `CLAUDE.md` — правила проекта и грабли.
2. `research/RESEARCH_SYNTHESIS.md` — предпроектный анализ (совет 10 агентов).
3. `docs/TZ_SLICES.md` — детальное ТЗ по срезам + схема БД. **Главный рабочий документ.**
4. Проверить среду: `PROJECT_DIR="$PWD" bash scripts/check_env.sh`.
5. Кодить срез 0 → 6 (см. TZ_SLICES).
