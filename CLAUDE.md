## Что это
CRM для логистической компании (контейнерные мультимодальные перевозки по **Среднему коридору / TITR**): Грузия→[ж/д]→Баку/Алят→[паром Каспий]→Туркменбаши→[ж/д]→Ташкент→[авто]→клиент. **Заменяет Excel.** Язык интерфейса — русский. Владелец: Давид (обращаться «Давид,» в финальных ответах).

## Три роли
- **manager** — вводит все данные, двигает стадии, комментарии. Главный ежедневный пользователь.
- **owner** — проверяет, берёт выгрузки, дашборд «где деньги / где застряло». Чтение + экспорт.
- **accountant** — деньги по плечам, инвойсы, «кто должен», маржа.

## КЛЮЧЕВОЕ доменное правило
**НЕ трекинг/GPS.** Менеджер **вручную** двигает СТАДИИ контейнера: «узнал → выбрал стадию → сохранилось → показывается». Каждая смена = запись в журнал `stage_event` (дата/время/автор/комментарий), **append-only**. Наглядно показать историю.

## Стек
React 18 + Vite + Tailwind (чистый, компоненты из 21st.dev) · Python **3.12** + FastAPI async + SQLAlchemy 2.x async + Alembic + Pydantic v2 · PostgreSQL · Argon2id + cookie-сессия + CSRF · openpyxl для экспорта.
⚠️ Системный Python здесь 3.14 — поднимать venv на **3.12 через pyenv** (wheels asyncpg/pydantic-core).

## НЕРУШИМЫЕ инженерные правила (грабли из прошлых проектов Давида)
1. **VARCHAR + CHECK, не нативный PG-enum** (enum не откатывается, ломает Alembic).
2. **Деньги — Decimal/NUMERIC(14,2)**, никогда float, никогда тип `money`.
3. **RBAC в сервисном слое** (FastAPI-зависимости), не DB-роли. 3 роли + флаг `can_see_money` (менеджеру не показывать маржу).
4. **Смена стадии = ОДНА сервисная функция, одна транзакция** (INSERT stage_event + UPDATE current_stage). Иначе рассинхрон. Журнал только INSERT.
5. **Одна транзакция на запрос** — сессия-зависимость commit/rollback; роутеры без explicit commit.
6. **Anti-IDOR** — scope по роли/доступу; чужой id → 404. Утечка чужих ставок/маржи = бизнес-риск.
7. **Soft-delete** (status='archived'), не физическое удаление — владелец сверяется по аудиту.
8. **Единица учёта = КОНТЕЙНЕР** (деньги/маржа/застревание на контейнер). Заказ клиента = фильтр.
9. **Каталог стадий и точки = Python-константы** (`app/domain/stages.py`), не хардкод по роутерам. Промотать в таблицу — только если владелец попросит правку.
10. **Alembic + сид с 1-го дня**; `CREATE EXTENSION IF NOT EXISTS citext` в upgrade().
