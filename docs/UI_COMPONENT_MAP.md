# Карта UI-компонентов — что брать из 21st.dev под каждый экран

> Каталог собран через **бесплатный** `search` (безлимитный). ID → используем `get21.sh <id>` для полного кода (⚠️ 2/день на free-тарифе — тянуть по мере вёрстки, начиная с самых нужных).
> Правило: 21st = СТРУКТУРА/приёмы, палитру и тон диктует наш дизайн + **taste-skill** (тема «стальной коридор», сдержанно, не неон).

## Дизайн-направление (напоминание)
Палитра из предпроектного анализа: графит-сталь `#1E2A32`, база `#F5F6F4`, акцент «морской сигнал» `#2E7D8A` (каспийское плечо). Семантика зон: LOW/booking — нейтраль; в пути — акцент; **застряло — янтарь `#D98A2B`**; доставлено/маржа+ — зелёный `#3E8E5A`; просрочка — красный. Дальтоник-безопасно (не только цветом — иконки/подписи).
